# KindleChess

Two-player chess for Kindle, based on IllusionChess (previously KChess). There is no AI opponent — both players play on the same device from opposite sides of the board.

## Install

Download and unzip the latest release, copy `KindleChess` and `KindleChess.sh` to the `documents` folder on your Kindle, then run `KindleChess.sh`.

## Skins

Each player can open Settings from their side of the board and choose a piece set and a board. Choices are saved on the device.

## Game analysis

After a game, a QR code is shown. Scanning it opens a full analysis of the game at [kc.01e.cc](https://kc.01e.cc).
